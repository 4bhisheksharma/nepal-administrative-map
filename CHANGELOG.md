# Changelog

## 0.0.1

Initial npm release (React sister of Flutter `nepal_administrative_map`):

- Interactive Canvas map: 7 provinces, 77 districts, 753 local levels
- Bilingual English / Nepali names, labels, tooltips and numbers
- Drill-down with animated zoom, pan/pinch/wheel, selection
- Choropleth colour scales, legend, search, markers, protected areas
- Typed gazetteer (`Province.gandaki`, `District.kaski`, …) and `nepal-administrative-map/core` entry
- Bundled TopoJSON (~423 KB); MIT code + CC BY 4.0 map data
